# datasets

`steam_sample.csv` — воспроизводимая выборка (`scripts/make_sample.py`: 10 000 игр, выпущенных
с 2020 года, seed 43) из датасета:

- **Steam Games Dataset — All Games (daily updates)**, автор Hubert Sidorowicz,
  <https://www.kaggle.com/datasets/hubertsidorowicz/steam-games-dataset-daily-updates>, версия 62;
- лицензия датасета — MIT; уведомление автора датасета сохраняется;
- исходные данные собраны автором из Steam Store API и SteamSpy.

Лицензии проекта (`LICENSE`, `LICENSE-CONTENT`) на этот каталог не распространяются.
